The Motivation

Why One Agent Isn't Enough

Before you build a team, you need to understand the three problems that make single-agent systems break down — and why splitting responsibilities between specialized agents fixes each one.

🧠
Problem 1 — Context Window Contamination

When a single agent both researches AND writes, it juggles two competing cognitive modes in one context window. Research mode favors breadth — collect everything, stay neutral, flag contradictions. Writing mode favors selectivity — pick the best angle, build narrative momentum, ignore tangents. These modes contaminate each other. The result: a half-researched summary, or a paralyzed researcher who can't commit to a narrative.

The fix: Separate context windows. The Research Agent's context is pure signal collection. The Writer Agent's context contains only the structured findings — not the noise.
⚙️
Problem 2 — Role Drift Under Instruction Pressure

Ask a single agent to "research the topic and write a summary" and it will start writing before it has finished researching — because the instruction contains implicit pressure to produce visible output. The research phase gets cut short. Alternatively, it over-researches and delivers a data dump instead of a summary. The two tasks have different completion signals and the agent can't satisfy both.

The fix: Each agent has one job and one completion signal. The Research Agent is done when it delivers a structured JSON handoff. The Writer Agent is done when it delivers a formatted summary.
🔁
Problem 3 — No Auditability of the Research-to-Writing Transition

When research and writing happen inside one agent, you can't inspect what the agent "knew" before it started writing. If the summary is wrong, was it a bad research phase or a bad synthesis phase? In a two-agent system, the handoff message is a first-class artifact — you can read it, validate it, and even route it to a human reviewer before the Writer Agent sees it.

The fix: The handoff message is structured and inspectable. The Orchestrator can validate, filter, or augment it before passing it downstream.

🔮 The handoff message is the most important artifact in this system. It's the structured JSON that the Research Agent passes to the Writer Agent — containing key findings, source summaries, confidence levels, and gaps. It determines everything the Writer Agent can and cannot say. In this lab you will see exactly what it looks like — and why its structure matters.
